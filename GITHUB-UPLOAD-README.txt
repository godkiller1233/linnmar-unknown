GITHUB UPLOAD

1. Extract this project.
2. Double-click UPLOAD-TO-GITHUB.bat.
3. If it reports Git or GitHub CLI missing, install them from the links it prints.
4. Sign into GitHub in the browser window.
5. Choose a repository name and private/public.
6. Press Y to upload.

IMPORTANT: If anything fails, the window stays open and prints the full error. A copyable log is saved as github-upload.log in this folder.

The script refuses to stage .env, data, uploads, or node_modules.
